# 💣 נטרול הפצצה — חידת שפת סימנים + פצצה מכנית

**הרעיון:** פצצה מכנית מופעלת כשמישהו נעמד מולה. צג מתחיל לספור אחורה מ-01:00, וזרוע עם סיכה מתקדמת ב"תקתוקים", דרך גלגלי שיניים, לעבר בלון. הזמזם מצפצף יותר ויותר מהר.
כדי לנטרל אותה צריך **לסמן מילה בשפת הסימנים מול המצלמה של המחשב**. כשהאתר מזהה את כל הסימנים לפי הסדר, הוא שולח פקודה לארדואינו בכבל USB, והמנוע נעצר.

```
 [שחקן] ──► HC-SR04 (חיישן 1) ──► הצג סופר אחורה והזרוע מתחילה לזוז
    │
    └─ מסמן מול המצלמה ──► אתר (MediaPipe) ──USB──► ארדואינו: "D" ──► המנוע נעצר ✔
                                    הצג הגיע ל-00:00 ──► 💥 בום
```

## דרישות הפרויקט — איך הן מתקיימות

| דרישה | אצלנו |
|---|---|

## 🖐️ האתר (זיהוי שפת סימנים)

האתר נמצא בתיקייה `web/`. הוא משתמש ב-**MediaPipe Hands** של גוגל, שמוצא 21 נקודות על כל יד, ובמסווג **KNN** (השכנים הקרובים) שלומד מהדוגמאות **שאת מקליטה**.
לכן הוא עובד עם **כל** שפת סימנים, כולל שפת הסימנים הישראלית, ובלי צורך במאגר מוכן.
כל הקבצים (כולל המודל) נמצאים בתיקייה, כך שהאתר עובד **בלי אינטרנט**.

### הפעלה
מצלמה וחיבור לארדואינו עובדים רק כשהאתר רץ דרך שרת מקומי ולא בפתיחה כפולה על הקובץ. הכי פשוט:

**אפשרות א': Python** (אם מותקן):
```bash
cd web
python -m http.server 8000
```
ואז פותחים ב-**Chrome** את `http://localhost:8000`

**אפשרות ב': VS Code** עם התוסף **Live Server**: קליק ימני על `web/index.html` ← *Open with Live Server*.

> ⚠️ חובה Chrome או Edge. החיבור לארדואינו (Web Serial) לא עובד בפיירפוקס או בספארי.

### סט מוכן: שפת סימנים אמריקאית (ASL)
במסך האימון יש כפתור **"טעינת אותיות ASL"**. הוא טוען 24 אותיות (A–Y בלי J ו-Z, שהן אותיות עם תנועה) שכבר אומנו מ-3,000 תמונות מצלמה אמיתיות. אם עוד לא הוגדרה מילה, הכפתור גם מגדיר את המילה `B,O,X`.
- טבלה של איך נראית כל אות: `web/asl-letters.jpg` (מופיעה גם באתר)
- **מילים מומלצות** (אותיות שהכי פחות מתבלבלות זו בזו): `BOX`, `WOW`, `COOL`, `LOCK`
- **כדאי להימנע** מהזוגות הדומים: M/T/N/S, R/U/V
- הכי מדויק: לטעון את הסט, **ובנוסף** להקליט את האותיות של המילה עם הידיים שלך
- מקור התמונות: [Zenodo 7563598](https://zenodo.org/records/7563598), רישיון CC BY 4.0. הבנייה מחדש נעשית עם `node tools/build-asl.js`

### שימוש
1. **אימון סימנים:** כותבים שם לסימן (למשל `ש`), לוחצים "הקלט", ואחרי ספירה לאחור מחזיקים את הסימן 3 שניות. **מקליטים כל סימן 2–3 פעמים**, בזוויות ומרחקים קצת שונים.
2. **המילה הסודית:** כותבים את שמות הסימנים לפי הסדר עם פסיקים: `ש,ל,ו,ם`
3. **בדיקה:** מתחת למצלמה מופיע מה שזוהה, ביטחון (כמה מתוך 5 שכנים הסכימו) ומרחק. אם זה מזהה סימנים לא נכונים, מורידים את "רף המרחק". אם זה לא מזהה כלום, מעלים.
4. **גיבוי!** "שמירה לקובץ" ← ובבית הספר "טעינה מקובץ". האימון נשמר רק בדפדפן שבו הוקלט.
5. **משחק:** "חיבור לארדואינו" ← בוחרים את פורט ה-USB. מעכשיו כשמישהו נעמד מול הפצצה המשחק מתחיל לבד, ופס ההתקדמות באתר מראה איפה המחט נמצאת.
   בלי ארדואינו לוחצים "התחל" והאתר מריץ טיימר משלו (טוב לתרגול).

### טיפים לזיהוי טוב
- **תאורה טובה** על הידיים, רקע לא עמוס.
- לבחור סימנים ש**שונים זה מזה בצורת היד**. זוגות דומים מאוד (למשל אותיות שנבדלות רק בתנועה) קשים לזיהוי.
- המערכת מזהה **צורת יד קפואה**, לא תנועה. סימן שכולו תנועה: מקליטים את התנוחה הסופית שלו.
- בין שני סימנים זהים ברצף (למשל `ל,ל`) צריך להוריד את היד לרגע.
- כדאי לבחור מילה של 3–4 סימנים: מספיק קשה כדי להיות חידה ומספיק קצר ל-60 שניות.
