# 💣 נטרול הפצצה — חידת שפת סימנים + פצצה מכנית

**הרעיון:** פצצה מכנית מופעלת כשמישהו נעמד מולה. מחט על עגלה מתחילה לנסוע לאט לעבר בלון, והזמזם מצפצף יותר ויותר מהר.
כדי לנטרל אותה צריך **לסמן מילה בשפת הסימנים מול המצלמה של המחשב**. כשהאתר מזהה את כל הסימנים לפי הסדר, הוא שולח פקודה לארדואינו בכבל USB, והמנוע נעצר.

```
 [שחקן] ──► HC-SR04 (חיישן 1) ──► ארדואינו מתחיל להזיז את המחט
    │
    └─ מסמן מול המצלמה ──► אתר (MediaPipe) ──USB──► ארדואינו: "D" ──► המנוע נעצר ✔
                                                   מתג גבול (חיישן 2) נלחץ ──► 💥 בום
```

## דרישות הפרויקט — איך הן מתקיימות

| דרישה | אצלנו |
|---|---|
| ארדואינו | Arduino Uno שמנהל את כל הפצצה |
| חיישן 1 | **חיישן מרחק אולטרסוני HC-SR04**: מזהה שחקן שעומד מול הפצצה ומפעיל אותה |
| חיישן 2 | **מתג גבול (מיקרו-סוויץ')** בקצה המסילה: מזהה שהעגלה הגיעה לבלון → "בום" ועצירה |
| תנועה מכנית | **מנוע צעד 28BYJ-48** שמלפף חוט על גלגלת ומושך עגלה עם מחט לאורך מסילה |
| החידה | זיהוי שפת סימנים במצלמה (תוכנה), שעוצר את התנועה המכנית |

## 🔧 הפצצה המכנית

### רשימת חלקים
| חלק | כמות | הערות |
|---|---|---|
| Arduino Uno + כבל USB | 1 | |
| מנוע צעד 28BYJ-48 + כרטיס ULN2003 | 1 | מגיעים יחד, זולים מאוד, נמצאים ברוב ערכות הארדואינו |
| HC-SR04 | 1 | |
| מיקרו-סוויץ' (מתג גבול עם זרוע) | 1 | |
| זמזם **פסיבי** | 1 | |
| לד אדום + לד ירוק + 2 נגדים 220Ω | | |
| ספק 5V חיצוני / סוללות 4×AA | 1 | למנוע (עדיף לא להזין אותו מה-5V של הארדואינו) |
| קרטון עבה / עץ דיקט / פלקס | | בסיס, מסילה ועגלה |
| חוט דיג / חוט תפירה חזק | | |
| גלגלת: פקק בקבוק / סליל חוטים ריק | 1 | מודבק על ציר המנוע |
| 2 קשיות או 2 שיפודי עץ | | מסילה שהעגלה מחליקה עליה |

### איך בונים (מכניקה)

```
          🎈 בלון (קשור מעל המנוע)
          │
  ┌───────┴──┐ [מתג גבול]          ◄── חוט נמשך ──        ┌──────────┐
  │  מנוע +  │◄════════════════════════════════════════════│ 📍 עגלה  │~~~ גומייה ~~~┤
  │  גלגלת   │                                             └──────────┘
  ══════════════════════════════ מסילה (2 שיפודים) ════════════════════════════════
```

המנוע מלפף חוט ומושך את העגלה **אליו**, ולכן הבלון והמתג נמצאים בצד של המנוע. הסיכה על העגלה מצביעה לכיוון המנוע והבלון.

1. **בסיס:** קרש/קרטון באורך כ-35 ס"מ.
2. **מסילה:** שני שיפודים מקבילים (או פרופיל אלומיניום U) שהעגלה מחליקה עליהם.
3. **עגלה:** חתיכת קרטון קטנה עם 2 קשיות מודבקות מתחתיה, שמושחלות על השיפודים. על העגלה מדביקים את הסיכה.
4. **המנוע והבלון באותו צד:** המנוע בקצה המסילה, הבלון קשור **ליד המנוע** (קצת מעליו או לצדו), והסיכה מכוונת אליו. המנוע מלפף את החוט ומושך את העגלה (ואת הסיכה) לכיוון הבלון.
5. **מתג הגבול** מודבק ממש לפני הבלון, כך שהעגלה לוחצת עליו ברגע שהסיכה פוגעת. זה מה שאומר לארדואינו "בום".
6. **החזרה להתחלה:** גומייה דקה מהצד השני מחזירה את העגלה כשהמנוע משחרר את החוט (פקודת איפוס R).

> 💡 **למה גלגלת ולא בורג הברגה?** עם מוט מושחל M8 המנוע הזה צריך כ-10 דקות לעבור 20 ס"מ, שזה איטי מדי. עם גלגלת בקוטר 2 ס"מ, סיבוב אחד מושך ~6 ס"מ, ו-20 ס"מ לוקחים בערך 60 שניות. בדיוק הזמן שרוצים לחידה.

### כיול
ב-`arduino/bomb/bomb.ino` למעלה:
- `TRAVEL_STEPS`: מספר הצעדים מההתחלה עד הבלון. מודדים: 2048 צעדים = סיבוב אחד = היקף הגלגלת (π × קוטר).
  לגלגלת 2 ס"מ ומסלול 20 ס"מ: 20 ÷ 6.28 × 2048 ≈ **6500**.
- `TIME_SECONDS`: כמה זמן יש לשחקן (ברירת מחדל 60).
- `ARM_DISTANCE`: מאיזה מרחק (ס"מ) החיישן מפעיל את הפצצה.

### חיבורים
| רכיב | פין בארדואינו |
|---|---|
| ULN2003 IN1, IN2, IN3, IN4 | 8, 9, 10, 11 |
| ULN2003 + / − | ספק 5V חיצוני (+ GND משותף עם הארדואינו!) |
| HC-SR04 TRIG / ECHO | 6 / 7 (VCC→5V, GND→GND) |
| מתג גבול | 2 ו-GND (בלי נגד: משתמשים ב-INPUT_PULLUP) |
| זמזם פסיבי | 3 ו-GND |
| לד אדום / לד ירוק | 4 / 5 (כל אחד דרך נגד 220Ω ל-GND) |

### הלוגיקה של הארדואינו
| מצב | מה קורה | מה מעביר למצב הבא |
|---|---|---|
| **IDLE** | מחכה | HC-SR04 רואה מישהו קרוב מ-60 ס"מ למשך 1.5 שנ', או פקודת `S` מהאתר |
| **ARMED** | לד אדום, המנוע מתקדם, הזמזם מצפצף ומאיץ | `D` מהאתר → **DEFUSED**. מתג גבול נלחץ → **BOOM** |
| **DEFUSED** | המנוע נעצר, לד ירוק, מנגינת ניצחון | `R` → חוזר להתחלה |
| **BOOM** | המנוע נעצר, צליל פיצוץ | `R` → חוזר להתחלה |

## 🖐️ האתר (זיהוי שפת סימנים)

האתר נמצא בתיקייה `web/`. הוא משתמש ב-**MediaPipe Hands** של גוגל, שמוצא 21 נקודות על כל יד, ובמסווג **KNN** (השכנים הקרובים) שלומד מהדוגמאות **שאת מקליטה**.
לכן הוא עובד עם **כל** שפת סימנים, כולל שפת הסימנים הישראלית, ובלי צורך במאגר מוכן.
כל הקבצים (כולל המודל) נמצאים בתיקייה, כך שהאתר עובד **בלי אינטרנט**.

### הפעלה
מצלמה וחיבור לארדואינו עובדים רק כשהאתר רץ דרך שרת מקומי ולא בפתיחה כפולה על הקובץ. הכי פשוט:

**אפשרות א': Python** (אם מותקן):
```bash
cd web
python -m http.server 8000
```
ואז פותחים ב-**Chrome** את `http://localhost:8000`

**אפשרות ב': VS Code** עם התוסף **Live Server**: קליק ימני על `web/index.html` ← *Open with Live Server*.

> ⚠️ חובה Chrome או Edge. החיבור לארדואינו (Web Serial) לא עובד בפיירפוקס או בספארי.

### סט מוכן: שפת סימנים אמריקאית (ASL)
במסך האימון יש כפתור **"טעינת אותיות ASL"**. הוא טוען 24 אותיות (A–Y בלי J ו-Z, שהן אותיות עם תנועה) שכבר אומנו מ-3,000 תמונות מצלמה אמיתיות. אם עוד לא הוגדרה מילה, הכפתור גם מגדיר את המילה `B,O,X`.
- טבלה של איך נראית כל אות: `web/asl-letters.jpg` (מופיעה גם באתר)
- **מילים מומלצות** (אותיות שהכי פחות מתבלבלות זו בזו): `BOX`, `WOW`, `COOL`, `LOCK`
- **כדאי להימנע** מהזוגות הדומים: M/T/N/S, R/U/V
- הכי מדויק: לטעון את הסט, **ובנוסף** להקליט את האותיות של המילה עם הידיים שלך
- מקור התמונות: [Zenodo 7563598](https://zenodo.org/records/7563598), רישיון CC BY 4.0. הבנייה מחדש נעשית עם `node tools/build-asl.js`

### שימוש
1. **אימון סימנים:** כותבים שם לסימן (למשל `ש`), לוחצים "הקלט", ואחרי ספירה לאחור מחזיקים את הסימן 3 שניות. **מקליטים כל סימן 2–3 פעמים**, בזוויות ומרחקים קצת שונים.
2. **המילה הסודית:** כותבים את שמות הסימנים לפי הסדר עם פסיקים: `ש,ל,ו,ם`
3. **בדיקה:** מתחת למצלמה מופיע מה שזוהה, ביטחון (כמה מתוך 5 שכנים הסכימו) ומרחק. אם זה מזהה סימנים לא נכונים, מורידים את "רף המרחק". אם זה לא מזהה כלום, מעלים.
4. **גיבוי!** "שמירה לקובץ" ← ובבית הספר "טעינה מקובץ". האימון נשמר רק בדפדפן שבו הוקלט.
5. **משחק:** "חיבור לארדואינו" ← בוחרים את פורט ה-USB. מעכשיו כשמישהו נעמד מול הפצצה המשחק מתחיל לבד, ופס ההתקדמות באתר מראה איפה המחט נמצאת.
   בלי ארדואינו לוחצים "התחל" והאתר מריץ טיימר משלו (טוב לתרגול).

### טיפים לזיהוי טוב
- **תאורה טובה** על הידיים, רקע לא עמוס.
- לבחור סימנים ש**שונים זה מזה בצורת היד**. זוגות דומים מאוד (למשל אותיות שנבדלות רק בתנועה) קשים לזיהוי.
- המערכת מזהה **צורת יד קפואה**, לא תנועה. סימן שכולו תנועה: מקליטים את התנוחה הסופית שלו.
- בין שני סימנים זהים ברצף (למשל `ל,ל`) צריך להוריד את היד לרגע.
- כדאי לבחור מילה של 3–4 סימנים: מספיק קשה כדי להיות חידה ומספיק קצר ל-60 שניות.
